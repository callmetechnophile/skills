# V0.3 Rust Crate Public Interfaces & Domain Data Structures

This document defines the strongly-typed public API contracts, domain structures, error definitions, and traits for all V0.3 Rust crates.

---

## 1. Task Engine (`task-intelligence`)

### Domain Types
```rust
use serde::{Deserialize, Serialize};
use std::collections::HashSet;

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub enum TaskDomain {
    Frontend,
    Backend,
    Database,
    Auth,
    DevOps,
    Security,
    Testing,
    Core,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub enum TaskIntent {
    Create,
    Fix,
    Optimize,
    Audit,
    Sync,
    General,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TaskRequest {
    pub raw_prompt: String,
    pub forced_workflow: Option<String>,
    pub target_agent: Option<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct NormalizedTask {
    pub task_id: uuid::Uuid,
    pub original_task: String,
    pub normalized_task: String,
    pub domains: HashSet<TaskDomain>,
    pub intent: TaskIntent,
}

#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq, Eq)]
pub enum ComplexityBand {
    Low,
    Medium,
    High,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ComplexityAssessment {
    pub scope_breadth: u8,        // 0..=2
    pub technical_coupling: u8,   // 0..=2
    pub uncertainty: u8,          // 0..=2
    pub risk: u8,                 // 0..=2
    pub parallelism: u8,          // 0..=2
    pub total_score: u8,          // 0..=10
    pub band: ComplexityBand,
    pub method: String,
}
```

### Public Trait
```rust
#[async_trait::async_trait]
pub trait TaskComplexityEvaluator: Send + Sync {
    async fn evaluate(
        &self,
        task: &NormalizedTask,
    ) -> Result<ComplexityAssessment, TaskIntelligenceError>;
}
```

## 4. Skill Ranking Engine (`skill-ranking`)

### Domain Types
```rust
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RankingBreakdown {
    pub task_relevance: f32,         // 40% weight
    pub capability_completeness: f32,// 20% weight
    pub provenance_maintenance: f32, // 15% weight
    pub security_trust: f32,         // 15% weight
    pub runtime_compatibility: f32,  // 10% weight
    pub raw_lexical_score: f32,
    pub raw_semantic_score: f32,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RankedSkill {
    pub metadata: SkillMetadata,
    pub total_score: f32, // 0.000 ..= 1.000
    pub breakdown: RankingBreakdown,
    pub security_decision: String,
    pub compatibility_decision: String,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RankingResult {
    pub selected: Option<RankedSkill>,
    pub alternatives: Vec<RankedSkill>,
    pub rejections: Vec<RejectionRecord>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RejectionRecord {
    pub skill_id: String,
    pub reason: String,
    pub details: String,
}
```

### Public Trait
```rust
#[async_trait::async_trait]
pub trait SkillRanker: Send + Sync {
    async fn rank(
        &self,
        candidates: &[SkillMetadata],
        query: &str,
        target_agent: &str,
    ) -> Result<RankingResult, RankingError>;
}
```

## 8. Skill Lifecycle & Ledger (`skill-lifecycle`)

### Domain Types
```rust
use serde::{Deserialize, Serialize};
use std::path::PathBuf;

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct InstalledSkill {
    pub skill_id: String,
    pub name: String,
    pub version: String,
    pub source: String,
    pub commit_sha: String,
    pub license: String,
    pub installation_path: PathBuf,
    pub target_agent: String,
    pub content_hash: String,
    pub trust_status: TrustStatus,
    pub installed_at: chrono::DateTime<chrono::Utc>,
    pub last_verification: chrono::DateTime<chrono::Utc>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct VerificationReport {
    pub total: usize,
    pub intact: usize,
    pub modified: usize,
    pub missing: usize,
    pub details: Vec<SkillIntegrityStatus>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct SkillIntegrityStatus {
    pub skill_id: String,
    pub name: String,
    pub status: String, // "INTACT", "MODIFIED", "MISSING_OR_CORRUPT"
    pub verified: bool,
}
```

### Public Trait
```rust
#[async_trait::async_trait]
pub trait LifecycleLedger: Send + Sync {
    async fn list_installed(&self) -> Result<Vec<InstalledSkill>, LifecycleError>;
    async fn record_install(&self, skill: InstalledSkill, force: bool) -> Result<(), LifecycleError>;
    async fn verify_all(&self) -> Result<VerificationReport, LifecycleError>;
    async fn remove(&self, skill_id: &str) -> Result<Option<InstalledSkill>, LifecycleError>;
}
```
