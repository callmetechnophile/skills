# V0.2 Architectural Baseline & Specification Contract

**Version:** V0.2.0  
**Status:** Frozen Stable Baseline  
**Language:** Node.js (ES Modules, ECMAScript 2022+)  
**Runtime Requirement:** Node.js `>= 20.0.0`  
**Purpose:** Serves as the immutable specification and parity benchmark for the V0.3 Rust migration.

---

## 1. Module Inventory & Responsibilities

| Module Path | Primary Export / Class | Responsibilities |
|---|---|---|
| `src/router.mjs` | `sortIssue()`, `routeTask()` | CLI entry point, coordinating triage, discovery, ranking, security, and activation planning. |
| `src/registry.mjs` | `rankSkills()` | Backward-compatible ranking facade backed by BM25 and HybridRanker. |
| `src/intelligence/task-normalizer.mjs` | `normalizeTask()` | Cleans whitespace, extracts action intent, detects domain keywords (`frontend`, `backend`, `database`, `auth`, `devops`, `security`, `testing`). |
| `src/intelligence/complexity-analyzer.mjs` | `ComplexityAnalyzer` | Computes 5-dimension rubric (scope breadth, coupling, uncertainty, risk, parallelism) into total score (0–10) and band (`LOW`, `MEDIUM`, `HIGH`). |
| `src/intelligence/issue-sorter.mjs` | `IssueSorter` | Formulates triage records, decomposes complex tasks into component-bounded work packages (`WP-1`, `WP-2`...) with explicit dependencies. |
| `src/intelligence/schemas/task-schema.mjs` | `TRIAGE_SCHEMA`, `validateTriageSchema()` | JSON schema and runtime validation engine for triage output. |
| `src/discovery/registry-base.mjs` | `SkillRegistry` | Abstract base class defining registry contract (`search`, `getMetadata`, `getVersions`, `resolveSource`, `retrieveSkillContent`, `verifyProvenance`). |
| `src/discovery/local-registry.mjs` | `LocalRegistry` | Scans `skills/` directory, parses YAML frontmatter, reads `catalog/manifest.json`. |
| `src/discovery/installed-registry.mjs` | `InstalledRegistry` | Queries workspace-installed skills recorded in `.installed-skills.json`. |
| `src/discovery/skillsdirectory-registry.mjs` | `SkillsDirectoryRegistry` | Queries local index or live endpoint, coordinates resumable pagination sync. |
| `src/discovery/directory-resolver.mjs` | `DirectoryResolver` | Inspects upstream GitHub Git tree, locates valid `SKILL.md` paths, rejects ambiguous matches. |
| `src/ranking/lexical-matcher.mjs` | `LexicalMatcher` | BM25 retrieval with weighted fields (Name 3x, Tags 2x, Description 1x, Category 1x). |
| `src/ranking/embedding-matcher.mjs` | `EmbeddingMatcher` | Cosine similarity using pluggable embeddings with local character 3-gram fallback. |
| `src/ranking/hybrid-ranker.mjs` | `HybridRanker` | 5-factor normalized reranking engine with explainable breakdowns. |
| `src/security/integrity.mjs` | `computeStringHash()`, `computeFileHash()` | SHA-256 cryptographic digest calculation. |
| `src/security/trust-scanner.mjs` | `TrustScanner` | Static AST/regex inspection for exfiltration, prompt injection overrides, destructive commands, obfuscated code. |
| `src/security/trust-policy.mjs` | `TrustPolicy` | Enforces 6 trust states (`UNSCANNED`, `SCANNING`, `APPROVED`, `RESTRICTED`, `REJECTED`, `QUARANTINED`). |
| `src/activation/activation-planner.mjs` | `ActivationPlanner` | Phased activation engine: Discovery -> Selection -> Installation check -> Trust gate -> Compatibility check -> Activation. |
| `src/activation/activation-report.mjs` | `ActivationReport` | Formats activation results into JSON and Markdown reports with SHA-256 validation. |
| `src/orchestration/dependency-graph.mjs` | `DependencyGraph` | Constructs DAG, computes topological waves via Kahn's algorithm, plans Mode A, Mode B, and Mode C fallback. |
| `src/orchestration/runtime-adapters/adapters.mjs` | `getRuntimeAdapter()`, `AntigravityAdapter`, `ClaudeCodeAdapter`, `CodexAdapter` | Target agent runtime integration and capability checking. |
| `src/lifecycle/installed-tracker.mjs` | `InstalledTracker` | Maintains `.installed-skills.json`, detects local modifications via hash comparisons, prevents overwrites. |

## 4. CLI Interface Behavior & Exit Codes

| Command | Normal Exit Code | Failure Exit Code | Primary Flags |
|---|---|---|---|
| `npm run sort -- "<task>"` | 0 | 1 (general), 2 (missing task) | `--json`, `--workflow <mode>` |
| `npm run route -- "<task>"` | 0 | 1 (general), 2 (missing task) | `--json`, `--workflow`, `--agent`, `--no-network` |
| `npm run find -- "<query>"` | 0 | 2 (missing query) | `--json`, `--no-network`, `--agent`, `--max-skills` |
| `npm run sync:catalog` | 0 | 1 (network/API error) | `--json`, `--page-size`, `--max-pages`, `--restart` |
| `npm run install:skill -- <repo> <skill>` | 0 | 1 (resolution fail / CLI fail), 2 (bad args) | `--execute`, `--dry-run`, `--agent`, `--json` |
| `npm run list:skills` | 0 | - | `--json` |
| `npm run verify:skills` | 0 (all intact) | 1 (modified/missing detected) | `--json` |
| `npm run update:skills` | 0 | 1 (check fail) | `--json` |

## 5. Security & Trust Boundaries

1. **Untrusted Input Boundary:** All content in third-party `SKILL.md` files, shell scripts, Python scripts, and repository trees is treated as untrusted data.
2. **Static Gate:** Must pass static scanning for prompt injection, credential exfiltration, destructive disk commands, and base64 obfuscation before activation.
3. **Execution Gate:** Discovery and installation planning are strictly separated from installation execution (`--execute` required).
4. **Instruction Immunity:** Skill instructions are loaded as bounded contextual guidance and are never permitted to override host system prompts, developer constraints, or safety policies.

---

## 6. Known Limitations to Overcome in V0.3

1. **Cold-Start Performance:** Node.js process startup and script loading takes ~150–250ms per CLI invocation. V0.3 Rust binary target: `< 15ms`.
2. **Catalogue Search Scale:** In-memory array filtering in Node.js slows down as the index exceeds 5,000 skills. V0.3 Rust target: Tantivy inverted-index sub-50ms search for 100,000+ skills.
3. **Runtime Distribution:** Node.js V0.2 requires pre-installed Node 20+. V0.3 Rust target: self-contained static single binaries for Linux, macOS, and Windows.
