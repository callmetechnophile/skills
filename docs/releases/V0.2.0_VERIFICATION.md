### AC-07: Explainable Skill Ranking
- **Status:** **PASS**
- **Evidence:** `HybridRanker` combines BM25 lexical term overlap (`LexicalMatcher`), semantic n-gram cosine similarity (`EmbeddingMatcher`), and a 5-factor normalized reranking rubric:
  1. Task Relevance: 40%
  2. Capability Completeness: 20%
  3. Provenance & Maintenance: 15%
  4. Security & Trust: 15%
