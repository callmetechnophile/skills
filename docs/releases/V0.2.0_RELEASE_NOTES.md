## Highlights

V0.2.0 represents a complete engineering remediation that transforms the initial proof-of-concept into a functional, secure, testable, and deterministic skill routing and activation engine for modern AI coding agents.

### 1. Task Intelligence & Structured Issue Triage
- **Deterministic Complexity Scoring:** Evaluates scope breadth, technical coupling, uncertainty, risk/blast radius, and parallelism across a 0–10 point rubric, categorizing tasks into `LOW`, `MEDIUM`, or `HIGH`.
- **Architectural Work Package Decomposition:** Replaces generic single-package outputs with component-bounded work packages (database, backend, auth, frontend, devops) with explicit dependency chains.
- **Runtime JSON Schema Validation:** Guarantees strict compliance of triage outputs with the formal triage schema.

### 2. Multi-Registry Skill Discovery & Exact Tree Resolution
- **Unified Registry Abstraction:** Connects `LocalRegistry` (core repository skills), `InstalledRegistry` (workspace-installed skills), and `SkillsDirectoryRegistry` (public metadata catalogue).
- **Exact Upstream Directory Resolution:** Inspects upstream GitHub Git trees to locate the true folder containing `SKILL.md`. Eliminates fabricated directory names and rejects ambiguous matches.
- **Resumable Catalogue Sync:** Syncs the public SkillsDirectory index with offset-based pagination and deduplication.

### 3. Hybrid 5-Factor Ranking & Reranking
- **BM25 Lexical Retrieval:** Computes term frequencies with field weighting (Name 3x, Tags 2x, Description 1x).
- **Zero-Cost Semantic Cosine Fallback:** Pluggable embedding interface backed by a local character n-gram vectorizer.
- **Explainable Reranking:** Transparent breakdown across Task Relevance (40%), Capability Completeness (20%), Provenance (15%), Security (15%), and Compatibility (10%).

### 4. Security & Trust Layer
- **Static AST & Pattern Scanner:** Detects credential exfiltration (`curl -d @.env`), prompt injection / instruction override attempts, destructive shell commands (`rm -rf /`), base64 eval obfuscation, and unpinned downloads piped to shell.
- **6-State Trust Machine:** Enforces `UNSCANNED`, `SCANNING`, `APPROVED`, `RESTRICTED`, `REJECTED`, and `QUARANTINED` states.
- **Cryptographic Integrity:** Computes SHA-256 hashes of all loaded instructions and blocks tampered skills.

### 5. Orchestration, DAG Scheduling & Honest Fallback
- **Topological Wave Execution:** Constructs directed acyclic graphs (DAGs) and groups independent work packages into parallel execution waves.
- **Mode C Sequential Fallback:** If live sub-agent concurrency is unavailable in the host runtime, linearizes packages in dependency order with explicit disclosure, never claiming fake concurrency.
- **Runtime Adapters:** Standardized adapters for Antigravity, Claude Code, and Codex.

### 6. Installed Skill Lifecycle Management
- **Persistent Ledger:** Tracks installed skills in `.installed-skills.json` with commit SHA, installation path, and content hashes.
- **Anti-Overwrite Protection:** Detects local user modifications and prevents silent overwriting during reinstalls.
- **CLI Commands:** Added `npm run list:skills`, `npm run verify:skills`, and `npm run update:skills`.
