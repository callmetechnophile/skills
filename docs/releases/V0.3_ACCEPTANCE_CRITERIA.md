# V0.3 Rust Core Release Acceptance Criteria

This specification defines the quality gates, validation standards, and acceptance criteria required before V0.3 can be declared ready for general release and prior to decommissioning the Node.js baseline.

> **Status Legend:** `PASS` | `FAIL` | `NOT VERIFIED` | `BLOCKED` | `DEFERRED`  
> **Last Evaluated:** V0.3.2.2 (`feat/rust-core-v0.3`, verified CI baseline `6abf6aba151711f0c8224e055d95d908f3667865`)  
> **Release Readiness:** **NOT READY FOR FULL RELEASE** (pending `RUST-AC-16` differential parity harness & `RUST-AC-17` performance benchmarks)

---

## 1. Mandatory Acceptance Criteria (Blocking Gates)

| ID | Category | Requirement Description | Status | Automated Test / CI Evidence | Manual Review / Scope Notes |
|---|---|---|---|---|---|
| **RUST-AC-01** | **Build & Toolchain** | Cargo workspace builds with zero warnings across all 13 crates on stable Rust `1.80+`. | **PASS** | `cargo clippy --workspace --all-targets -- -D warnings` (0 warnings), `cargo fmt --all -- --check` (0 diffs), CI run `46180380298`. | Verified on Ubuntu, macOS, Windows. |
| **RUST-AC-02** | **Crate Completeness** | Every crate (`router-core`, `task-intelligence`, `issue-analyzer`, `skill-registry`, `skill-discovery`, `skill-ranking`, `skill-security`, `skill-activation`, `agent-orchestrator`, `runtime-adapters`, `skill-lifecycle`, `execution-engine`, `router-cli`) contains functional implementation with zero placeholder stubs. | **PASS** | `cargo test --workspace` (44 passed, 0 failed across all 13 crates). | Manual source audit confirmed no stub modules remain. |
| **RUST-AC-03** | **Metadata Compatibility** | Existing `SKILL.md` frontmatter, `catalog/manifest.json`, and `.installed-skills.json` parse without modification or data loss. | **PASS** | `skill-registry` (`test_parse_frontmatter`, `test_parse_frontmatter_metadata_version_and_license`), `skill-lifecycle` ledger roundtrip & corrupt backup tests. | Manual review confirmed `UNSPECIFIED` defaults replace fabricated metadata. |
| **RUST-AC-04** | **Task Triage Parity** | `task-intelligence` and `issue-analyzer` produce triage records with schema compliance against V0.2 fixtures. | **PASS** | `task-intelligence` (3 tests), `issue-analyzer` (2 tests), `router-cli` `test_cli_sort_and_route_and_find_json`. | Schema structure reviewed against V0.2 `IssueSorter`. |
| **RUST-AC-05** | **Discovery Engine** | Discovers local repository skills, installed ledger skills, and public SkillsDirectory metadata. | **PASS** | `skill-discovery` (3 tests including `test_sync_catalog_validation_pagination_and_error_preservation`), `router-cli` integration tests. | Live external `skillsdirectory.com` API contract remains unverified without live network tests. |
| **RUST-AC-06** | **Exact Directory Resolution** | Inspects GitHub tree, enforces `truncated` check (`TREE_TRUNCATED`), and identifies exact folder containing `SKILL.md`. Rejects ambiguous or fabricated matches. | **PASS** | `test_tree_directory_resolution`, `test_tree_resolution_complete_truncated_empty_ambiguous_and_fallbacks`. | Mocked HTTP server validates truncation, master fallback, and 429 rate-limit handling. |
| **RUST-AC-07** | **Hybrid Ranking Parity** | BM25 + semantic n-gram cosine similarity yields deterministic rankings on benchmark queries. | **PASS** | `skill-ranking::tests::test_ranking_bm25_and_hybrid`. | Cross-engine differential benchmark comparison is tracked under `RUST-AC-16`. |
| **RUST-AC-08** | **Security & Trust Enforcement** | Static scanner flags prompt injection overrides, exfiltration, and destructive commands; blocks `REJECTED`, `QUARANTINED`, `UNSCANNED`, and `SCANNING` skills from activation and installation. | **PASS** | `skill-security` (3 tests), `skill-activation` (6 tests including `test_unscanned_and_scanning_states_are_blocked`), `skill-lifecycle` (`test_install_rejects_malicious_supporting_file_and_traversal_and_symlinks`). | Static regex scanner limitations documented in security assessment. |
| **RUST-AC-09** | **Truthful Activation Reports** | Activation engine verifies loaded instruction and installed directory SHA-256 hashes and outputs truthful JSON/Markdown reports. | **PASS** | `skill-activation` (`test_hash_mismatch_blocks_activation`), `router-core` (`test_tampered_installed_directory_blocks_activation`). | Verified `HASH_MISMATCH` blocks activation. |
| **RUST-AC-10** | **Runtime Compatibility Gate** | Correctly filters incompatible skills based on target agent (`antigravity`, `claude-code`, `codex`). | **PASS** | `runtime-adapters::tests::test_runtime_adapter_selection`. | Checked adapter trait implementations manually. |
| **RUST-AC-11** | **DAG Scheduling & Wave Sorter** | Constructs acyclic graphs using `petgraph`, detects cycles with errors, and groups work packages into dependency waves. | **PASS** | `agent-orchestrator` (`test_dag_waves_and_fallback`, `test_cycle_detection`), `execution-engine` (2 tests). | Cycle detection verified by unit test. |
| **RUST-AC-12** | **Honest Sequential Fallback** | Applies Mode C sequential fallback with explicit downgrade disclosure when subagent bridge is absent. | **PASS** | `agent-orchestrator::tests::test_dag_waves_and_fallback`. | Verified downgrade notice in CLI output. |
| **RUST-AC-13** | **Truthful Runtime Integration** | Uses supported runtime adapter formatting and marks automated subagent dispatch as externally managed when unsupported. | **PASS** | `runtime-adapters` and `execution-engine` unit tests. | Manual review of adapter handoff formatting. |
| **RUST-AC-14** | **CLI Command Parity** | `skill-router` binary supports `sort`, `route`, `find`, `sync-catalog`, `install-skill`, `list-skills`, `verify-skills`, and `check-updates` (with legacy colon aliases). | **PASS** | `crates/router-cli/tests/cli_integration.rs` (3 binary integration tests). | Legacy `update:skills` / `update-skills` emit deprecation warning to stderr. |
| **RUST-AC-15** | **State Persistence & Integrity** | Ledger survives restarts, detects directory/supporting-file tampering via canonical SHA-256, prevents silent overwrites (fail-closed), rejects concurrent ledger creation/deletion/mutation, and rolls back failed transactions. | **PASS** | `skill-lifecycle` (11 tests including `test_v0321_update_intact_reinstall_untracked_and_fail_closed_matrix`, `test_v0322_concurrent_ledger_integrity_and_rollback`, `test_limits_and_restricted_and_transaction_rollback`). | Manual review: cross-resource OS-crash atomicity (FS rename + ledger rename) and cross-process advisory file locking remain documented limitations. |
| **RUST-AC-16** | **Cross-Engine Regression Tests** | All 7 E2E scenarios from V0.2 pass on Node.js (`npm test`: 33/33) and Rust (`cargo test`: 44/44). | **NOT VERIFIED** | Independent suites pass (`npm test` 33/33; `cargo test --workspace` 44/44). | Automated differential JSON-schema comparison harness across all 7 scenarios not yet implemented. |
| **RUST-AC-17** | **Performance Benchmarks** | Cold-start latency P95 `< 20ms`; local BM25 search over 10,000 skills P95 `< 50ms`. | **NOT VERIFIED** | None yet. | `cargo bench` harness not yet added. |
| **RUST-AC-18** | **Multi-Platform CI** | GitHub Actions CI passes on Ubuntu, macOS, Windows, Node.js 20, and Node.js 22. | **PASS** | GitHub Actions `pull_request` run [`46180380298`](https://github.com/callmetechnophile/skills/actions/runs/46180380298) on commit `6abf6aba151711f0c8224e055d95d908f3667865`: `Node 20 on ubuntu-latest`, `Node 22 on ubuntu-latest`, `Rust Core CI (ubuntu-latest)`, `Rust Core CI (macos-latest)`, `Rust Core CI (windows-latest)` all `success`. | Note: `push` run `46180376029` had transient `Set up job` runner failures on Node jobs while all 3 Rust jobs passed; `pull_request` run `46180380298` passed all 5 jobs. |
| **RUST-AC-19** | **Complete Decommissioning** | Node.js routing engine is retired without leaving duplicate or competing routing logic in the repo. | **DEFERRED** | `npm test` (33/33) remains active compatibility baseline. | Deferred until `RUST-AC-16` and `RUST-AC-17` pass. |
