# V0.3 Rust Core Release Acceptance Criteria

This specification defines the quality gates, validation standards, and acceptance criteria required before V0.3 can be declared ready for general release and prior to decommissioning the Node.js baseline.

> **Status Legend:** `PASS` | `FAIL` | `NOT VERIFIED` | `BLOCKED` | `DEFERRED`  
> **Last Evaluated:** V0.3.2 (`feat/rust-core-v0.3`)

---

## 1. Mandatory Acceptance Criteria (Blocking Gates)

| ID | Category | Requirement Description | Status | Evidence / Notes |
|---|---|---|---|---|
| **RUST-AC-01** | **Build & Toolchain** | Cargo workspace builds with zero warnings across all 13 crates on stable Rust `1.80+`. | **PASS** | `cargo clippy --workspace --all-targets -- -D warnings` (0 warnings, 0 errors); `cargo fmt --all -- --check` (0 diffs). |
| **RUST-AC-02** | **Crate Completeness** | Every crate (`router-core`, `task-intelligence`, `issue-analyzer`, `skill-registry`, `skill-discovery`, `skill-ranking`, `skill-security`, `skill-activation`, `agent-orchestrator`, `runtime-adapters`, `skill-lifecycle`, `execution-engine`, `router-cli`) contains functional implementation with zero placeholder stubs. | **PASS** | All 13 crates implemented and exercised by 42 workspace tests (`cargo test --workspace`: 42 passed, 0 failed). |
| **RUST-AC-03** | **Metadata Compatibility** | Existing `SKILL.md` frontmatter, `catalog/manifest.json`, and `.installed-skills.json` parse without modification or data loss. | **PASS** | `skill-registry` tests (`test_parse_frontmatter`, `test_parse_frontmatter_metadata_version_and_license`), `skill-lifecycle` ledger roundtrip & corrupt backup tests. |
| **RUST-AC-04** | **Task Triage Parity** | `task-intelligence` and `issue-analyzer` produce triage records with schema compliance against V0.2 fixtures. | **PASS** | `task-intelligence` (3 tests) + `issue-analyzer` (2 tests) + `router-cli` `sort --json` integration test pass. |
| **RUST-AC-05** | **Discovery Engine** | Discovers local repository skills, installed ledger skills, and public SkillsDirectory metadata. | **PASS** | `skill-discovery` (3 tests) + `router-cli` `find` & `sync-catalog` tests pass with mocked HTTP. Live external SkillsDirectory API contract remains unverified (`API_CONTRACT_UNVERIFIED` without live endpoint). |
| **RUST-AC-06** | **Exact Directory Resolution** | Inspects GitHub tree, enforces `truncated` check (`TREE_TRUNCATED`), and identifies exact folder containing `SKILL.md`. Rejects ambiguous or fabricated matches. | **PASS** | `test_tree_directory_resolution` + `test_tree_resolution_complete_truncated_empty_ambiguous_and_fallbacks` pass. |
| **RUST-AC-07** | **Hybrid Ranking Parity** | BM25 + semantic n-gram cosine similarity yields deterministic rankings on benchmark queries. | **PASS** | `skill-ranking::tests::test_ranking_bm25_and_hybrid` passes. Differential cross-engine benchmark fixture comparison is `NOT VERIFIED`. |
| **RUST-AC-08** | **Security & Trust Enforcement** | Static scanner flags prompt injection overrides, exfiltration, and destructive commands; blocks `REJECTED`, `QUARANTINED`, `UNSCANNED`, and `SCANNING` skills from activation and installation. | **PASS** | `skill-security` (3 tests), `skill-activation` (6 tests including `test_unscanned_and_scanning_states_are_blocked`), `skill-lifecycle` (`test_install_rejects_malicious_supporting_file_and_traversal_and_symlinks`). |
| **RUST-AC-09** | **Truthful Activation Reports** | Activation engine verifies loaded instruction and installed directory SHA-256 hashes and outputs truthful JSON/Markdown reports. | **PASS** | `skill-activation` (`test_hash_mismatch_blocks_activation`) + `router-core` (`test_tampered_installed_directory_blocks_activation`). |
| **RUST-AC-10** | **Runtime Compatibility Gate** | Correctly filters incompatible skills based on target agent (`antigravity`, `claude-code`, `codex`). | **PASS** | `runtime-adapters::tests::test_runtime_adapter_selection` passes. |
| **RUST-AC-11** | **DAG Scheduling & Wave Sorter** | Constructs acyclic graphs using `petgraph`, detects cycles with errors, and groups work packages into dependency waves. | **PASS** | `agent-orchestrator` (`test_dag_waves_and_fallback`, `test_cycle_detection`) + `execution-engine` (2 tests) pass. |
| **RUST-AC-12** | **Honest Sequential Fallback** | Applies Mode C sequential fallback with explicit downgrade disclosure when subagent bridge is absent. | **PASS** | `agent-orchestrator::tests::test_dag_waves_and_fallback` passes. |
| **RUST-AC-13** | **Truthful Runtime Integration** | Uses supported runtime adapter formatting and marks automated subagent dispatch as externally managed when unsupported. | **PASS** | Verified in `runtime-adapters` and `execution-engine` unit tests. |
| **RUST-AC-14** | **CLI Command Parity** | `skill-router` binary supports `sort`, `route`, `find`, `sync-catalog`, `install-skill`, `list-skills`, `verify-skills`, and `check-updates` (with legacy colon aliases). | **PASS** | `crates/router-cli/tests/cli_integration.rs` (3 binary integration tests) pass. |
| **RUST-AC-15** | **State Persistence & Integrity** | Ledger survives restarts, detects directory/supporting-file tampering via canonical SHA-256, prevents silent overwrites, and rolls back failed transactions. | **PASS** | `skill-lifecycle` (9 tests: atomic ledger, multi-file install, path validation, rollback on `FilesystemReplace` and `LedgerCommit` failures). |
| **RUST-AC-16** | **Cross-Engine Regression Tests** | All 7 E2E scenarios from V0.2 pass on Node.js (`npm test`: 33/33) and Rust (`cargo test`: 42/42). | **NOT VERIFIED** | Both suites pass independently (33 Node + 42 Rust); formal differential JSON-schema comparison harness across all 7 scenarios not yet automated. |
| **RUST-AC-17** | **Performance Benchmarks** | Cold-start latency P95 `< 20ms`; local BM25 search over 10,000 skills P95 `< 50ms`. | **NOT VERIFIED** | `cargo bench` harness not yet added in V0.3.2. |
| **RUST-AC-18** | **Multi-Platform CI** | GitHub Actions CI passes on Ubuntu, macOS, and Windows. | **NOT VERIFIED** | `.github/workflows/test.yml` configured for `[ubuntu-latest, macos-latest, windows-latest]`; pending remote CI run on pushed V0.3.2 HEAD SHA. |
| **RUST-AC-19** | **Complete Decommissioning** | Node.js routing engine is retired without leaving duplicate or competing routing logic in the repo. | **DEFERRED** | Retained intentionally until V0.3 parity and CI are independently verified; `npm test` (33/33) remains active baseline. |
