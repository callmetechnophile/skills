# V0.3 Rust Core Release Acceptance Criteria

This specification defines the quality gates, validation standards, and acceptance criteria required before V0.3 can be declared ready for general release and prior to decommissioning the Node.js baseline.

---

## 1. Mandatory Acceptance Criteria (Blocking Gates)

| ID | Category | Requirement Description | Verification Method |
|---|---|---|---|
| **RUST-AC-01** | **Build & Toolchain** | Cargo workspace builds with zero warnings across all crates on stable Rust `1.80+`. | `cargo build --workspace --all-targets` |
| **RUST-AC-02** | **Crate Completeness** | Every crate (`router-core`, `task-intelligence`, `issue-analyzer`, `skill-registry`, `skill-discovery`, `skill-ranking`, `skill-security`, `skill-activation`, `agent-orchestrator`, `runtime-adapters`, `skill-lifecycle`, `router-cli`) contains functional implementation with zero placeholder stubs. | Source audit + unit test coverage |
| **RUST-AC-03** | **Metadata Compatibility** | Existing `SKILL.md` frontmatter, `catalog/manifest.json`, and `.installed-skills.json` parse without modification or data loss. | Deserialization compatibility test suite |
| **RUST-AC-04** | **Task Triage Parity** | `task-intelligence` and `issue-analyzer` produce triage records with 100% schema compliance and parity against V0.2 fixtures. | JSON schema validator + differential test harness |
| **RUST-AC-05** | **Discovery Engine** | Discovers local repository skills, installed ledger skills, and public SkillsDirectory metadata. | Integration tests against test fixtures |
| **RUST-AC-06** | **Exact Directory Resolution** | Inspects GitHub tree and identifies exact folder containing `SKILL.md`. Rejects ambiguous or fabricated matches. | Mocked Git tree resolution test suite |
| **RUST-AC-07** | **Hybrid Ranking Parity** | BM25 + semantic n-gram cosine similarity yields identical top-3 candidate rankings on standard benchmark query fixtures. | Differential ranking comparison test |
| **RUST-AC-08** | **Security & Trust Enforcement** | Static scanner flags prompt injection overrides, exfiltration, and destructive commands; blocks `REJECTED` and `QUARANTINED` skills from activation. | Unit tests covering all 6 security rule categories |
| **RUST-AC-09** | **Truthful Activation Reports** | Activation engine verifies loaded instruction SHA-256 hashes and outputs truthful JSON/Markdown reports. | End-to-end activation tests |
| **RUST-AC-10** | **Runtime Compatibility Gate** | Correctly filters incompatible skills based on target agent (`antigravity`, `claude-code`, `codex`). | Adapter compatibility tests |
| **RUST-AC-11** | **DAG Scheduling & Wave Sorter**| Constructs acyclic graphs using `petgraph`, detects cycles with errors, and groups work packages into dependency waves. | Graph scheduler test suite |
| **RUST-AC-12** | **Honest Sequential Fallback** | Applies Mode C sequential fallback with explicit downgrade disclosure when subagent bridge is absent. | End-to-end execution mode tests |
| **RUST-AC-13** | **Truthful Runtime Integration**| Uses real supported runtime integration mechanisms and marks automated subagent dispatch as externally managed when unsupported. | Runtime adapter inspection |
| **RUST-AC-14** | **CLI Command Parity** | `skill-router` binary supports all commands (`sort`, `route`, `find`, `sync:catalog`, `install:skill`, `list:skills`, `verify:skills`, `update:skills`) and flags (`--json`, `--verbose`, `--dry-run`, `--agent`, `--workflow`, `--max-skills`, `--no-network`). | CLI integration test runner |
| **RUST-AC-15** | **State Persistence & Integrity**| Ledger survives restarts, detects file tampering via content hash mismatch, and prevents silent overwrites without `--force`. | Lifecycle persistence tests |
| **RUST-AC-16** | **Cross-Engine Regression Tests**| All 7 E2E scenarios from V0.2 pass on the Rust binary with matching exit codes and JSON schemas. | Differential test suite |
| **RUST-AC-17** | **Performance Benchmarks** | Cold-start latency P95 `< 20ms`; local BM25 search over 10,000 skills P95 `< 50ms`. | `cargo bench` benchmark report |
| **RUST-AC-18** | **Multi-Platform CI** | GitHub Actions CI passes on Ubuntu, macOS, and Windows. | GitHub Actions CI run |
| **RUST-AC-19** | **Complete Decommissioning** | Node.js routing engine is retired without leaving duplicate or competing routing logic in the repo. | Repository audit |
